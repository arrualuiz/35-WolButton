# WolButton

App Android simples para enviar Wake-on-LAN para o PC.

## Configuracao usada

- MAC: `AA:BB:CC:DD:EE:FF`
- Broadcast: `192.168.0.255`
- Porta: `9`

## Como abrir no Android Studio

1. Abra o Android Studio.
2. Selecione **Open**.
3. Escolha a pasta `WolButton`.
4. Aguarde o Gradle Sync.
5. Conecte o Android antigo com depuracao USB ativada.
6. Clique em **Run**.

## Como testar

1. Instale o app no Android.
2. Deixe o celular no mesmo Wi-Fi do PC.
3. Desligue o PC pelo Windows.
4. Abra o app e toque em **Ligar PC**.

Se nao funcionar desligado, teste primeiro com o PC em suspensao.
